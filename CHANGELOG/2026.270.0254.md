# 2026.270.0254 — feat: add the check-alpine-repo R10 bed for the published package repo

## Summary of changes

Relocate the `check-alpine-repo` R10 bed (and the box + candies it deploys) into this repo,
which OWNS the artifact the bed tests. Per-file:

- `charly.yml` (new, +192): declares this project so the repo hosts the bed that proves its own
  published artifact. It adds three candies and one deploy:
  - `sudo-nopasswd` — installs `sudo` and grants the uid-1000 account passwordless sudo, so the
    in-container `apk` check steps can elevate (a charly box runs as uid 1000; Alpine ships no
    sudo and the check executor does no implicit escalation).
  - `alpine-repo-tools` — bakes `curl` into the bed's image (`distro.alpine.package: [curl]` +
    its `alpine-repo-tools-curl` presence check) so the repo-install check steps add no runtime
    OS dependency.
  - `alpine-repo-box` — the bed's pod workload (minimal `docker.io/library/alpine:3.24`),
    composing `sudo-nopasswd` + `alpine-repo-tools`.
  - `check-alpine-repo` — the `pod` deploy (`disposable: true`, `lifecycle: dev`) that installs
    the charly apk RSA key, adds the published repo
    (`opencharly.github.io/charly-alpine/amd64`), `apk add charly`, asserts the PACKAGED
    `/usr/bin/charly` reports the same version `apk` recorded, and proves the welded command
    plugins dispatch project-less from `/tmp`.
- `.gitignore` (new, +16): the standard generated-artifact rules (`.build/`, `.check/`,
  `output/`, editor scratch, migration backups).

`charly.yml` `version:` is the current schema `2026.261.1747`. Placement: the bed, box and
candies live in the repo that OWNS the published artifact; no core/sdk code, no alias-file
growth.
